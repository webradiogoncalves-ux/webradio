ARQUITETURA

PlayTV       -> catálogo de Canais -> URL autorizada ->GetFut       -> catálogo de Jogos  -> URL autorizada -> PLAYER ÚNICO
Novecalizando-> catálogo de Novelas/Filmes -> URL autorizada ->/

Não são três APKs embutidos. São três adaptadores de fonte alimentando um único player.

IMPORTANTE:
- Não há URLs inventadas para SBT, novelas ou jogos.
- O stream MPEG-TS de teste já capturado pode ser usado para validar o player.
- Se uma fonte exigir login, sessão, token ou outra proteção, o aplicativo deve usar o mecanismo autorizado; não há bypass de DRM/autenticação.
