# Web Rádio Vem Comigo no Glória — Lite

Projeto Android nativo, sem WebView para a rádio.

## Funções
- Rádio ao vivo por transmissão direta.
- Reconexão automática quando a transmissão falhar.
- Volume + / -.
- Hora Certa com os áudios horários locais.
- Bíblia Sagrada com os 66 livros, capítulos e versículos carregados por capítulo.
- Devocional diário.
- Palavra do Dia com conteúdo que muda diariamente.
- Compartilhar rádio.
- Tela fixa, sem rolagem na tela principal.

A Bíblia usa os arquivos JSON públicos do Free.Bible, no formato documentado por eles: `https://free.bible/bible/{translation}/{book}/{chapter}.json`.

O projeto não armazena senha do servidor de transmissão.
