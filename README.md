# WEBTV FULL

Projeto Android nativo, criado do zero a partir de uma lista M3U fornecida pelo usuário.

## Interface
- WEBTV FULL
- abas CANAIS / NOVELAS / JOGOS
- categorias em cards
- lista de canais
- pesquisa de categorias
- um único player nativo Media3/ExoPlayer
- player em tela cheia e orientação paisagem

## Catálogo
A lista original é pré-processada por categoria e comprimida em `.m3u.gz`, para evitar arquivos individuais grandes demais para o upload pelo GitHub. Conteúdo adulto foi excluído deste build focado.

## Build
GitHub Actions usa Gradle 8.11.1 e Java 17.
