# Web Rádio Vem Comigo no Glória — Lite

Projeto Android nativo, leve e sem WebView.

### Funções incluídas
- Rádio ao vivo por transmissão direta.
- Hora Certa automática: 24 chamadas de hora, tocadas na virada da hora.
- Modo escuro como padrão.
- Bíblia Sagrada com 66 livros, capítulos e paginação fixa, usando dados bíblicos de domínio público por capítulo.
- Devocional diário.
- Palavra do Dia diária.
- Controle de volume.
- Compartilhar rádio.
- Ícone principal baseado no logo do app de referência.

### Transmissão
Listener configurado com o servidor mostrado pelo proprietário:
`http://sapircast.caster.fm:19513/QKnuH`

Nenhuma senha de transmissão é armazenada no projeto.

### GitHub
