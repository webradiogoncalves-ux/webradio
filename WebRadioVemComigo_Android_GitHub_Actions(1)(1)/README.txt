WEB RÁDIO VEM COMIGO NO GLÓRIA — VERSÃO PROFISSIONAL 2.0

Incluído:
- Nome do aplicativo: Web Rádio Vem Comigo no Glória
- Ícone personalizado baseado na arte enviada
- Tela de abertura (splash)
- Interface mobile em modo retrato
- Player de rádio integrado
- Permissão de Internet
- Compatibilidade Android 6.0+

Para gerar o APK:
1. Abra a pasta no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Build > Build APK(s).
4. O APK estará em app/build/outputs/apk/debug/app-debug.apk.

Observação: o ambiente desta conversa não contém o Android SDK necessário para
compilar o APK binário diretamente.
