WEB RÁDIO VEM COMIGO NO GLÓRIA - GERAR APK

COMO COLOCAR NO GITHUB
1. Extraia este ZIP no computador.
2. Entre no seu repositório do GitHub.
3. Coloque o conteúdo extraído DIRETAMENTE na raiz.
4. A raiz deve conter:
   app/
   build.gradle
   settings.gradle
   .github/workflows/build-apk.yml

NÃO coloque o ZIP dentro do GitHub.

COMO GERAR O APK
1. GitHub -> Actions.
2. Abra "Build APK - Web Rádio Vem Comigo" (ou o workflow build-apk.yml).
3. Execute o workflow manualmente, se necessário.
4. Ao terminar, abra a execução.
5. Em Artifacts, baixe "WebRadio-VemComigo-APK".
6. Dentro do arquivo baixado estará o app-debug.apk.

OBSERVAÇÃO
Este pacote contém o projeto Android e o workflow para o GitHub gerar o APK.
O APK binário não é incluído no ZIP porque a compilação precisa ser executada no ambiente Android/Gradle do GitHub Actions.
